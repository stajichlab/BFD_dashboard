[ ] - Gene-annotation gap-filling (proposed 2026-11-11; evidence in docs/analyses/kx2_kickx_reduction/annotation_check/ and docs/analyses/kx2_ku_pathway/tblastn/). Evidence so far: annotation misses are genome-specific. Ku was missed in Tieghemiomyces, Caulochytrium and Conidiobolus (found by tblastn), Massospora has 415 proteins, and the Antarctolithica MAGs miss many families. In 107 Coemansia strains, however, protein-mode BUSCO equals genome-mode BUSCO (median gap -0.2 points; none above 10) and the Ku, Pol4, ATR and Rad51 calls agree with tblastn, so no systematic loss is indicated there for conserved genes. Proposal: a validated, source-tagged miniprot gap-filling step after funannotate predict, only for genomes that fail a completeness check (large genome-vs-protein BUSCO gap, tiny proteome, MAG). First read what do_annotation_busco_gap already does (it diagnoses the 52 genome-BUSCO >= 90% / protein-BUSCO < 50% genomes stage by stage) and extend it instead of duplicating it; note the pipeline's protein evidence is a fungal SwissProt set aligned with diamond + exonerate (profile_funannotate.config, FUNANNOTATE_PREDICT). Safeguards: never overwrite an existing model, tag rescued models in the GFF, use one intron penalty everywhere, re-run BUSCO to measure the gain, pilot on 10-20 genomes. Do not adopt until the rescue passes its validation (at least 80% of recovered annotated loci translate cleanly and median identity to the annotated protein >= 0.95); that validation is in progress in docs/analyses/kx2_ku_pathway/family_trees/.
